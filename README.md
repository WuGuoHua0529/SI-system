# 📖 規範版本監控系統 (Standardized Inspection System) 

這是一套跨平台的桌面自動化工具，專門用於監控與追蹤各國/國際標準規範（如 IEC, ISO, ASTM 等）的最新版本發布狀態。透過自動化網路爬蟲技術，系統能定時在背景比對版本日期，並在有新版本時給予視覺化的紅點通知，大幅降低人工巡檢的時間成本。

## ✨ 主要功能特色

* **📡 多來源自動爬蟲**：支援包含 IEC, ISTA, ANSI, ASTM, DIN, ETSI, DNV, EN, ISO, JEDEC, JIS, MIL, RTCA, SAE, Telcordia, UN 等超過 15 種以上的規範來源。
* **⏰ 背景定時更新**：使用者可自訂每日自動更新時間。時間一到，系統會在背景默默執行比對，不干擾日常工作。
* **🔔 智慧紅點通知**：當爬蟲發現版本更新時，系統匣會自動亮起「紅點」，直到使用者點開畫面查看為止。
* **🔒 企業網域安全鎖 (Domain Restriction)**：內建存取權限控管機制。管理員可設定指定的 Windows 網域，限制非公司網域的私人電腦無法開啟此軟體，確保資料安全。
* **📊 Excel 無縫匯入**：支援一鍵匯入既有的 Excel 監控清單，快速建立追蹤任務。

## 📊 Excel 匯入格式說明 (重要)

系統支援直接匯入既有的 Excel 清單（`.xlsx`）。請確保您的 Excel 表格遵守以下直欄格式設計，由左至右必須包含以下 **4 個欄位**：

| 第 1 欄 (A) | 第 2 欄 (B) | 第 3 欄 (C) | 第 4 欄 (D) |
| :--- | :--- | :--- | :--- |
| **平台/類別 (Platform)** | **規範編號 (Standard_ID)** | **追蹤網址 (URL)** | **目前版本 (Current_Version)** |
| 例如：`IEC` | 例如：`60068-2-1` | `https://...` | 例如：`2023-01` |
| 例如：`ASTM` | 例如：`D4169` | `https://...` | 例如：`2022-04-15` |

**💡 填寫注意事項：**
1. **支援合併儲存格**：第一欄的「平台/類別」支援使用 Excel 的合併儲存格功能。系統匯入時會自動「向下遞補」分類名稱，不會遺漏。
2. **必填欄位**：第二欄（規範編號）與第三欄（追蹤網址）為必填。若網址為空，系統將自動跳過該筆資料並在匯入完成時提示。
3. **版本基準**：第四欄（目前版本）若有填寫，將自動設定為該規範的「舊版基準」。未來若網站上的日期大於此基準，系統即會判定為有更新。

## 📖 使用者操作手冊 (User Guide)

1. **設定權限網域**：
   * 第一次開啟系統時，點擊右上角「權限設定」。
   * 輸入貴公司的 Windows 網域名稱（例如：`IST`）並儲存。下次開啟時，非該網域的電腦將會被強制阻擋。若留白則不限制。
2. **匯入追蹤清單**：
   * 點選主畫面上方的「匯入 Excel」按鈕，選擇上述格式整理好的檔案。系統會自動依照分類將項目派發到對應的爬蟲模組，並略過已重複存在的項目。
3. **設定每日更新時間**：
   * 點擊右上角「時間設定」，輸入您希望系統每天在背景自動巡檢的時間（例如 `08:30`）。
4. **關於 UN 類別的特殊驗證**：
   * 當您的追蹤清單中包含 `UN` 來源時，系統在更新時會自動彈出一個瀏覽器視窗。這是為了通過聯合國網站的防護驗證。請**不要關閉或移動該視窗**，靜待幾秒鐘驗證通過後，系統便會自動關閉視窗接手後續更新。
5. **關閉與背景執行**：
   * 點擊右上角「X」關閉視窗，系統**不會退出**，而是會縮小至右下角系統匣（綠色小閃電圖示），持續為您把關。若要徹底退出，請對右下角圖示按右鍵選擇「退出」。

## 🛠️ 開發者環境建置 (Developer Setup)

如果您要在全新的電腦（例如 Windows 測試機）上運行此專案，請按照以下步驟建立環境：

**1. 複製專案**
```bash
git clone [您的 Git 網址]
cd SI-system
```

**2. 安裝 Python 依賴套件**
```bash
pip install -r requirements.txt
```

**3. 安裝 Playwright 瀏覽器核心 (⚠️ 重要！)**
由於 UN 等特定來源需要啟動真實瀏覽器，請務必執行此指令下載瀏覽器核心：
```bash
playwright install
```

**4. 啟動應用程式**
```bash
python main.py
```
